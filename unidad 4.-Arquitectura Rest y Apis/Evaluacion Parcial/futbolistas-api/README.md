# API REST de Futbolistas en PHP

**Alumno:** Jonathan García


### Obtener todos
- **GET** `http://localhost/futbolistas-api/futbolistas`

### Obtener por ID
- **GET** `http://localhost/futbolistas-api/futbolistas/1`

### Crear
- **POST** `http://localhost/futbolistas-api/futbolistas`
