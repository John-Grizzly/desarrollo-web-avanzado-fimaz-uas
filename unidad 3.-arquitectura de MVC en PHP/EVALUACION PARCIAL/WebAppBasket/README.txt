Proyecto WebAppBasket

1. Copia la carpeta WebAppBasket dentro de htdocs.
2. Importa el archivo database/schema.sql en phpMyAdmin.
3. Revisa config/DataBase.php:
   - host: localhost
   - db: proyecto
   - user: demo
   - password: 123

Si tu MySQL usa otro usuario o password, cambia esos datos.
